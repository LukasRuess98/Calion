## PRE-SUBMISSION CHECKLIST

## 1. MANUSCRIPT CONTENT

### 1.1 Title and Abstract
- [ ] Title is concise and descriptive (< 150 characters recommended)
- [ ] Abstract is 200-250 words
- [ ] Abstract states: purpose, methods, key results, conclusions
- [ ] Abstract is factual and avoids citations
- [ ] No abbreviations in abstract (except standard units)

### 1.2 Keywords
- [ ] Maximum 6 keywords provided
- [ ] Keywords use American spelling
- [ ] Keywords avoid plural terms where possible
- [ ] Keywords avoid multiple concepts (e.g., "heat pumps AND storage")
- [ ] Keywords not already in title (for better discoverability)

### 1.3 Highlights
- [ ] 3-5 bullet points provided
- [ ] Each highlight max 85 characters (including spaces)
- [ ] Highlights convey key innovations/findings
- [ ] Character count verified for each highlight

- [ ] Graphical abstract created
- [ ] Minimum size: 531 × 1328 pixels (h × w)
- [ ] Readable at 5 × 13 cm
- [ ] High resolution (300+ DPI)
- [ ] File formats: PNG, JPG, or TIFF
- [ ] File size < 5 MB

### 1.5 Manuscript Structure
- [ ] Introduction section present
- [ ] Materials and Methods section present
- [ ] Results section present
- [ ] Discussion section present
- [ ] Conclusions section present

## 2. FIGURES AND TABLES

### 2.1 Figure Requirements
- [ ] All figures cited in text in sequential order (Figure 1, Figure 2, ...)
- [ ] Each figure has a concise caption
- [ ] Figure captions are placed below figures
- [ ] Figures are high resolution (minimum 300 DPI)
- [ ] Vector formats (PDF, EPS) used where possible
- [ ] Figures readable at column width (8.5 cm single, 17.5 cm double)
- [ ] Font sizes readable when scaled (minimum 8pt)
- [ ] Color figures accessible to colorblind readers
- [ ] Figures have no backgrounds (white/transparent)
- [ ] All axes labeled with units
