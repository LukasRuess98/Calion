# Supplementary Material S1: Complete Mathematical Formulation

**For:** EnerGIS: A Modular MILP Framework for Industrial Heat Network Planning and Operations
**Journal:** Applied Energy
**Date:** 2025-11-18

## Overview

This supplementary file contains the complete mathematical formulation of the EnerGIS framework, including all equations, parameters, and variables. For a formatted LaTeX version with proper mathematical typesetting, see `formulation.tex` in the paper repository.

---

## Contents

1. **Complete MILP Formulation** - All equations with detailed explanations
2. **Parameter Tables** - Comprehensive list of all model parameters
3. **Variable Definitions** - All decision variables with units and bounds
4. **Constraint Catalog** - Detailed description of each constraint type
5. **Implementation Notes** - Correspondence with actual code
