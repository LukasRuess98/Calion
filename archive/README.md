# archive/

Development artifacts kept for reference. Not part of the active codebase.

| Subfolder | Contents |
|-----------|----------|
| `debug_scripts/` | Ad-hoc infeasibility diagnosis scripts (`diagnose_phase*.py`, `debug_*.py`) used during MILP debugging |
| `validation_scripts/` | One-off validation and sanity-check scripts (`validate_*.py`, `check_*.py`, `analyze_*.py`) |
| `data_generators/` | Scripts used to generate synthetic test datasets |
| `dev_docs/` | Working documents from refactoring phases (MILP linearization analysis, validation reports, QA checklists) |
| `logs_and_results/` | Old solver logs, test result text files, and one-off JSON validation outputs |
| `legacy_data/` | `Import_Data.xlsx` — original Excel input, superseded by `data/*.csv` |
