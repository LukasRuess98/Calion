{\footnotesize Heat-curve stages per family: HK0/HK1/HK2 unless the label carries
TVLFIX. \textbf{TES-ONLY} adds investable storage with \emph{no new HP/EB} (existing
plant unchanged) — only the new-investment set differs across the decomposition.
The existing generation park (incl.\ Stadtbach's 9.9\,MW electrode boiler) is identical
in every run of a network, baselines included; \emph{neither network has any existing
storage} (both start at 0\,MWh, so storage-hours are directly comparable). The
decomposition BASE\,$\to$\,HP-ONLY\,$\to$\,TES-ONLY\,$\to$\,FIX-HP attributes savings to
each investment; the chain FREE\,$\to$\,FREE-CO\,$\to$\,FREE-CO-HOT separates co-location
from hot charging (one factor changes per step). BASE-HK0 is the status-quo reference;
BASE-FIX/{}TVLFIX rows isolate the value of heat-curve control (alone, and with storage
via FIX-HP\,vs.\,FIX-HP\,(TVLFIX)).}
